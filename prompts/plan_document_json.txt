  - 'description': short explanation or purpose of that section.
  - 'subsections': an object with subsections (same structure) if any.
  - 'sources': an array with any source references you consider relevant.

For example:
{
  "Introduction": {
    "description": "Gives an overview of the topic.",
    "subsections": {
       "Scope": {
          "description": "Clarifies scope.",
          "subsections": {},
          "sources": []
       }
    },
    "sources": []
  },
  "Background": {
    "description": "Reviews existing literature.",
    "subsections": {},
    "sources": []
  }
}

Now return ONLY valid JSON, with no extra commentary. The topic is provided in the user message.
